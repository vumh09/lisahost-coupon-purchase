## 四、lisahost 购买教程里几个新手高频翻车点

最后再啰嗦几个我看到比较多人踩的坑，帮你少走点弯路。

**坑 1：优惠码填了没反应。** 八成是没点"验证"按钮。LisaHost 这点设计得不太友好，输入框看着像是填进去就生效，其实必须手动点验证才会计算折扣。下次卡在这里，先找"验证"按钮。

**坑 2：贪便宜买了个不合适的套餐。** 比如 199 元那款美国 9929 非原生 IP，价格是真香，但它流量只有 200G、带宽 50M、还是非原生 IP。如果你是想做 TikTok 矩阵或者跑流媒体，这种配置基本不够用，得往上选原生 IP 或双 ISP 家宽款。**先定用途再定套餐**，别反过来。

**坑 3：买了才发现线路不合适。** 不同机房、不同线路对国内三网的延迟和稳定性差别很大。建议买之前先看看 LisaHost 官方或者第三方测评里对应机房的实测数据，尤其是晚高峰的表现。好在有 48 小时退款兜底，拿到机器第一时间跑个测速，不行就退。

**坑 4：忘了用优惠码直接付款。** 这种事真的会发生……付完才发现没折扣，只能工单联系客服补，麻烦得很。所以养成习惯——**进购物车第一件事先填码、点验证、看金额变了，再往下走**。

**坑 5：SSH 连不上以为自己买错了。** LisaHost 的 SSH 端口默认是 22，但部分 NAT 机器可能需要先做端口转发。连不上的时候先去后台看看是不是 NAT 套餐，再看端口信息，别急着判定机器坏了。
